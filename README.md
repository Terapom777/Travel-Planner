# 旅プラン

iPhoneのホーム画面から使う、旅行計画用のWebアプリ(PWA)です。

- **候補**:行きたい場所をストックします(★必須、入場料、メモ)
- **プラン**:A案・B案のように複数の案を作れます
  - 大移動:飛行機(オープンジョー可)、レンタカーでのドライブ、レンタカー代、鉄道、バス
  - 日ごと:宿、回るスポット、食費などの1日の概算
- **比較**:案ごとの費用内訳、円換算の合計、運転距離と時間、★必須の場所を回れた数

## 自動で計算されるもの

| 項目 | 取得元 |
|---|---|
| 地図、ピン、ルート線 | Maps JavaScript API |
| 場所の検索、価格帯、評価 | Places API (New) |
| 移動時間、距離、ドライブの通行料、電車・バスの運賃 | Routes API(取れた場合のみ) |
| ガソリン代 | 運転距離 ÷ 燃費 × ガソリン価格(設定で変更可) |
| 為替レート(ドル→円) | Frankfurter(欧州中央銀行のレート、1日1回自動更新) |

データ(候補とプラン)は、端末のブラウザの中だけに保存されます。機種変更などに備えて、メニューの「データを書き出す」でバックアップを取ってください。

## 1. APIキーを用意する

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、支払い情報(クレジットカード)を登録します
2. 「APIとサービス」→「ライブラリ」で、次の3つを**有効化**します
   - Maps JavaScript API
   - Places API (New) ※名前に「(New)」が付いている方です
   - Routes API
3. 「認証情報」→「認証情報を作成」→「APIキー」でキーを作ります
4. 作ったキーに**制限**をかけます(必ず行ってください)
   - アプリケーションの制限:**ウェブサイト**を選び、公開先のURLを登録します(例:`https://あなたのID.github.io/*`)。PCで試すなら `http://localhost:8000/*` も追加します
   - APIの制限:上の3つのAPIだけを許可します
5. 念のため、「お支払い」→「予算とアラート」で、少額(例:1,000円)の予算アラートを設定しておくと安心です

> 個人が1回の旅行の計画に使う程度なら、各APIの毎月の無料枠に収まる見込みです。ドライブ区間の通行料の計算は、Routes APIの上位の料金区分(Pro)になります。ただし、結果は端末に保存して使い回すので、同じ区間を何度も問い合わせることはありません。

## 2. PCで試す

```sh
cd travel-planner
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開き、APIキーを入力します。

## 3. iPhoneで使う(GitHub Pagesで公開)

iPhoneから使うには、HTTPSのURLで公開する必要があります。いちばん手軽なのはGitHub Pagesです(無料)。

1. GitHubでリポジトリを作り、このフォルダの中身をpushします
2. リポジトリの Settings → Pages で、Branch を `main` / `(root)` にして保存します
3. 数分後、`https://あなたのID.github.io/リポジトリ名/` で公開されます
4. APIキーのウェブサイト制限に、このURLを追加します
5. iPhoneの**Safari**で開き、共有ボタン →「**ホーム画面に追加**」を選ぶと、アプリとして起動できます

> APIキーはコードの中には書かず、初回起動時に入力してiPhoneの中に保存する仕組みです。そのため、リポジトリを公開してもキーは漏れません。

## 4. フライト検索(任意)

アプリ内でGoogle Flightsの便の一覧を出すには、SerpApi(無料プランは月250回)と、キーを隠すためのCloudflare Workerを使います。

1. https://serpapi.com/ に登録し、ダッシュボードの「Api Key」をコピーします
2. https://dash.cloudflare.com/ に登録し、「Workers & Pages」→「作成」→「Hello World から開始」で Worker を作ります
3. 「コードを編集」で、[worker/flights-proxy.js](worker/flights-proxy.js) の中身に置き換えて「デプロイ」します
4. Worker の「設定」→「変数とシークレット」に次を登録します
   - `SERPAPI_KEY`(種類:シークレット):SerpApiのキー
   - `ALLOWED_ORIGINS`(種類:テキスト):`https://あなたのID.github.io`
5. Worker のURL(`https://〜.workers.dev`)を、アプリの メニュー →「設定」→「フライト検索の中継URL」に入れます

検索結果は6時間、端末に保存して使い回し、検索回数を節約します。座席クラス(エコノミー・ビジネスなど)を複数選ぶと、同じ便のクラスごとの価格を並べて比較できます。ただし、1クラスにつき検索1回分を使います。検索前に「区間の長さで変える」(例:搭乗4時間以内はエコノミー、それより長い区間はビジネス)を選ぶこともできます。また、乗り継ぎ便は「区間ごとにクラスを変えて見積もる」で、長距離だけビジネスのように区間ごとにクラスを変えた場合の合計(区間ごとに別々に買った場合の目安)も出せます。「条件をしぼる」では、到着リミット・乗り継ぎの待ち時間・予算の上限・アライアンス(複数可)を指定できます。「💡 安く探す」では、近くの空港をまとめて探す・日付を前後にずらして比べる・乗り継ぎ地で分けて買う・アメリカ向けの価格と比べる、ができます(相場はいつも表示)(Workerは最新の [worker/flights-proxy.js](worker/flights-proxy.js) に更新してください)。

## ファイル構成

```
index.html     画面の骨組み
style.css      見た目(ダークモード対応)
app.js         アプリの処理すべて
manifest.json  ホーム画面に追加したときの設定
sw.js          オフラインでもアプリ本体を開けるようにするキャッシュ
icon-*.png     アイコン
worker/        フライト検索の中継プログラム(Cloudflareに貼り付ける。GitHubには置かなくてもよい)
```
